## WHAT IS ROBOFLOW?
===============================================================================
Roboflow = Computer vision platform for training custom AI models
- Dataset management and annotation tools
- Custom model training on your specific data
- Model deployment (API or downloadable)
- Specialized for object detection, classification, segmentation

Key Difference from Current System:
- Current: Few-shot learning (5-8 examples, general AI guesses)
- Roboflow: Custom training (50-200+ labeled images, specialized model)

## HOW ROBOFLOW WORKS
===============================================================================
Training Process:
1. Collect Images → Upload building photos, video frames
2. Annotate Data → Draw bounding boxes, label buildings/people/activities
3. Train Model → Roboflow trains neural network on your specific data
4. Deploy Model → Get API or downloadable model for your exact use case

Frame-by-Frame Analysis (Same as Current):
- Roboflow analyzes individual frames, NOT full videos
- Your smart frame sampling workflow stays the same
- Only difference: Send frames to local Roboflow model vs Gemini API

## TECHNICAL IMPLEMENTATION
===============================================================================
Local Model Usage (After Download):

from roboflow import Roboflow
import ultralytics

# One-time setup
rf = Roboflow(api_key="your_key")
project = rf.workspace().project("campus-buildings")
model = project.version(1).model
model.download("yolov8", "path/to/local/model")

# Local inference (no API costs)
local_model = ultralytics.YOLO("path/to/local/model/weights/best.pt")

def analyze_frame_with_roboflow(self, frame_path):
    results = local_model(frame_path)
    buildings_detected = []
    
    for result in results:
        for box in result.boxes:
            buildings_detected.append({
                'building': result.names[int(box.cls)],
                'confidence': float(box.conf),
                'bbox': box.xyxy.tolist()
            })
    
    return buildings_detected
